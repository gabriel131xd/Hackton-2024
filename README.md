# Hackton-2024

Repositório com os desafios de lógica de programação propostos no Hackathon de 2024. Todos os exercícios foram desenvolvidos em Java utilizando o editor EditPlus.

☕ Importação obrigatória para leitura de dados

Todos os exercícios que utilizam entrada do usuário usam o Scanner.
Sempre utilize a importação padrão no início do código Java:
import java.util.Scanner;

🚀 Execução
Os arquivos .java podem ser executados em qualquer ambiente Java.
No EditPlus, basta compilar com javac e executar com java.
Recomendado usar terminal ou prompt para entrada dos dados.
